# ⏰ Digital Clock

A simple and clean **Digital Clock** created using **HTML, CSS, and JavaScript**.
This project displays the current time dynamically and helps demonstrate basic frontend development concepts.

## 🚀 Features

* 🕐 Displays current time
* 🔄 Updates time automatically
* 🎨 Clean and simple user interface
* 📱 Responsive design
* ⚡ Lightweight and fast
* 💻 Beginner-friendly project

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **JavaScript** – Clock functionality and real-time updates

## 💻 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/Digital-Clock.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
